# Figma 操作日志

> Agent 在 Figma 完成操作后的记录区。走查轮次产物（报告 / 修改清单 / 截图）归 `走查/`，不放这里。

## 文件组织

- 按**类型**组织，一个类型一个文件，例如 `需求卡片和标题.md`、`节点1_<主题>.md`、`节点2_<主题>.md`。
- 新类型出现时新建对应文件。
- 同一类型的后续操作（包括用户在会话外手工修改的补记）在文件末尾按日期追加小节，**只增不覆盖**。

## 小节格式

每次操作在对应文件末尾追加一节：

```markdown
## YYYY-MM-DD · <一句话摘要>

- 任务来源：<用户指令 / Linear 工单号 / 走查修改清单编号>
- 涉及节点：<节点名> · node_id `<id>` · <Figma 链接>
- 操作摘要：<做了什么，改了哪些属性 / 结构>
- 结果状态：已完成 / 部分完成（写明缺口）/ 待用户确认
```

## 截图证据

- 归 `日志/参考截图/`，命名 `YYYY-MM-DD-<说明>.png`。
- 日志正文里用相对路径引用。
