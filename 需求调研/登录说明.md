## Cloud Agent 用法

- 在 Cursor Dashboard → Cloud Agents → Secrets 添加 `KIRA_STAGING_EMAIL` 和 `KIRA_STAGING_PASSWORD`（建议设为本仓库范围的 secret）。Secrets 只注入**新启动**的 Cloud Agent，添加后要在新的 run 里使用。
- agent 开工前先确认变量存在，只检查变量名、不打印值：`env | cut -d= -f1 | rg '^KIRA_STAGING_'`。缺失时停下，请用户去 Dashboard 添加，不要让用户把密码贴进对话或仓库。
- 脚本里只从环境变量读取，示例（Playwright，系统 Chrome 在 `/usr/local/bin/google-chrome`）：

  ```js
  await page.getByPlaceholder('your@email.com').fill(process.env.KIRA_STAGING_EMAIL);
  await page.getByRole('button', { name: 'Next' }).click();
  await page.getByPlaceholder('Enter your password').fill(process.env.KIRA_STAGING_PASSWORD);
  await page.getByRole('button', { name: 'Log in' }).click();
  ```

- 登录态（`storageState` 等 cookie 文件）只放 `/tmp`，用完删除，不放进仓库。

## 登录路径（逐步，2026-09-15 已实测全程通过）

1. 打开 `https://staging.kira-learning.com/ai-tools/literacy-studio/`，视口 1440x900；等待跳转到 `/login/?callbackUrl=...`。
2. 登录页标题文案 `Hi! I'm Kira. Welcome! How would you like to continue?`，三个按钮：`Continue with email` / `Continue with Google` / `Continue with other provider`。点击 **`Continue with email`**。
3. 出现 `What's your email address?`，输入框 placeholder `your@email.com`。填入账号（Cloud Agent 读 `KIRA_STAGING_EMAIL`；本地读 `登录凭据.md`），点 **`Next`**（未填邮箱前为 disabled）。
4. 出现 `Welcome back! Enter your password to continue.`，密码框 placeholder `Enter your password`（右侧有显示 / 隐藏密码的眼睛图标；下方有 `Forgot your password?` 链接，不要点）。填入密码（**区分大小写**，Cloud Agent 读 `KIRA_STAGING_PASSWORD`；本地照 `登录凭据.md` 原样输入），点 **`Log in`**。
5. 成功：URL 变为 `https://staging.kira-learning.com/ai-tools/literacy-studio/`（callbackUrl 被正确带回），标签页标题 `Literacy Studio | Kira`，主标题 `Good morning, <用户名>`。以「标题含 `Literacy Studio | Kira`」作为登录成功的判定条件。
   失败：密码框下方出现红字 `The email or password you entered is incorrect`。最多重试 1 次；仍失败则停止、不点 `Forgot your password?`，向用户报告（先检查密码大小写）。
6. 二次验证 / 首次引导弹窗：**无**应用内弹窗。有头模式下 Chrome 可能弹浏览器自身的 `Save password?`（按钮 `Never` / `No thanks` / `Save`），点 `No thanks` 即可；Playwright 自动化上下文一般不会出现。
7. 定位方式：页面按钮的 `id` 是 `react-aria-*` 随机值，**不要用 id**；一律按可见文案（`getByRole('button', { name: '...' })`）或 placeholder 定位。
8. **Literacy Studio 的页面内容在 iframe 里**（外层只有侧栏）：iframe 地址为 `https://staging.kira-learning.com/tools/literacy-studio/...`。定位页面内元素前先取到这个 frame（例如 `page.frames().find(f => f.url().includes('/tools/literacy-studio'))`），在 frame 里查找和点击；直接在外层 `page` 上找不到 `View All Tasks` 等元素。
