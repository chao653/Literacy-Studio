# Linear 工单流程

## 读任务

- 用 Linear MCP 读工单（`get_issue` / `list_issues` / `list_comments`），**不退化成网页抓取**。
- MCP 掉线或鉴权失败时，提示用户重连后再继续，不用其他途径绕过。

## 处理与回评

- 处理完自动产出**评论草稿**，含三部分：改动范围 / 改动内容 / 相关链接（Figma 节点、文档），结尾 `cc @某人`（默认 cc 对象：待填）。
- 草稿交用户手动回评，**不代发**。

## 记录

- 每处理一单，在 `History.md` 追加一行：日期 / 工单 / 处理内容 / 状态。
