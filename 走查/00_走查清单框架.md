## B. 规范合规

| 检查项 | 依据 | 检查要点 |
| --- | --- | --- |
| token 绑定 | `设计执行/规范/design.md` + `figma-preferences.md` | 颜色 / 圆角 / 间距 / 阴影 / 文本样式是否全部绑定 semantic token；新建容器有无遗留默认白 `#FFFFFF` |
| auto layout | `设计执行/规范/figma-layer-naming.md` | 容器是否用 auto layout；方向 / 间距 / padding / 对齐是否合理；有无绝对定位滥用 |
| 命名 | `设计执行/规范/figma-layer-naming.md` + `命名规范.md` | 图层 / 组件 / 页面 / section 命名是否符合规范 |
| UI 文案大小写 | `设计执行/规范/写作规范.md` | 英文文案是否按组件映射表用 Sentence case / Title Case；禁 ALL CAPS、禁全小写；同页同角色是否一致 |
| 字重与图标 | `设计执行/规范/design.md` + `icons.md` | 字重是否在允许集合内；图标是否为 SVG 组件实例（禁键盘字符冒充）；图标来源是否为指定库 |

## 轮次产物约定

- 每轮产出两份文件，放本目录：`RN_报告.md` + `RN_修改清单.md`（N 为轮次，如 `R1_报告.md` / `R1_修改清单.md`）。
- 修改清单含状态列：**待改 / 已改 / 搁置**。修改后在**同一份清单**里复核勾销，不另开文件。
- 截图证据放 `走查/截图/`，命名 `RN-<序号>-<说明>.png`，与报告成对存放。
